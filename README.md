SmartStock
SmartStock is an Inventory and Warehouse Management System built with ASP.NET Core Web API and Entity Framework Core.
Features
•	Product Management
•	Warehouse Management
•	Inventory Tracking
•	Inventory Transactions
•	SQL Server Integration
Technology Stack
•	ASP.NET Core Web API
•	Entity Framework Core
•	SQL Server
•	Swagger / OpenAPI
Current Modules
•	Products
•	Warehouses
•	Inventory Balances
•	Inventory Transactions
•	Stock Receiving
