📦 SmartStock
SmartStock is an Inventory and Warehouse Management System built with ASP.NET Core Web API and Entity Framework Core. It helps organizations manage products, warehouses, inventory balances, and stock transactions with real-time inventory visibility and efficient warehouse operations.

🚀 Features
Product Management
Create, update, delete, and view products
Manage SKU information
Track product status and units of measure
Warehouse Management
Manage multiple warehouses
Maintain warehouse master data
Support inventory tracking across locations
Inventory Management
Track inventory balances by product and warehouse
Monitor quantity on hand
Manage reserved inventory
Calculate available inventory automatically
Inventory Transactions
Receive stock
Issue stock
Inventory adjustments
Stock transfers
Transaction history and auditing
API Features
RESTful API architecture
Entity Framework Core integration
SQL Server database support
OpenAPI/Swagger documentation
Clean project structure
